Autopilot controller (production)

Operational state (OFF / STARTING / ON / STOPPING / BLOCKED) is separate from the autonomy mode (the production level, the lower of global and category). The controller runs inside the scheduler daemon. It takes production ownership only at APPROVED_EXECUTION with active standing approvals, and it dispatches only cycle occurrences the unchanged 24-cycle schedule fired, one renderer at a time. Start and Stop are requests: the state shown is the one the backend has verified. Publishing, schedule, configuration, restart, deletion and git actions are permanently prohibited.
